# 「深いね」と言われる親子の話題プロンプト集

中学生の子どもと親が、夕食や車の中で少しだけ深い話をするための、AI用プロンプト集です。
AIが毎日3つの話題を「軽め」「中くらい」「深め」の順に出します。
話題は、政治・社会、経済・お金、恋愛、友だち・人間関係、成長・自分、部活・努力、将来・仕事、テクノロジー・AI、生き方・哲学、家族の10種類から、曜日ごとに入れかわります。

ChatGPT・Gemini・Claude のどれでも使えます。

## 使い方

1. [00_最初に1回だけ設定する](prompts/00_最初に1回だけ設定する.md) の設定文を、AIの「プロジェクト」や「Gem」に貼ります。[ ] の中は自分の家庭に合わせて書きかえます。
2. 毎日、AIに「今日の3つ」と送ります。
3. 出てきた3つのうち、その日の子どもの様子に合う1つだけを話します。

設定をしない場合は、[01_今日の3つ](prompts/01_今日の3つ.md) を毎回貼って使えます。

## 収録しているプロンプト

| ファイル | 使う場面 |
|---|---|
| [00_最初に1回だけ設定する](prompts/00_最初に1回だけ設定する.md) | AIに決まりごとを覚えさせる設定文です。以後は合図の一言で動きます |
| [01_今日の3つ](prompts/01_今日の3つ.md) | 毎日の本体です。3つの話題を、切り出しの一言・問い・深めるヒントつきで出します |
| [02_1週間分](prompts/02_1週間分.md) | 1週間ぶん21の話題を一覧で出します |
| [03_ニュースから](prompts/03_ニュースから.md) | その日のニュースを、立場の両側つきの問いに変えます（検索できるAI向け） |
| [04_返事から深める](prompts/04_返事から深める.md) | 子どもの返事にどう返すと話が続くかを相談します |
| [05_月に1回のふりかえり](prompts/05_月に1回のふりかえり.md) | 1か月の反応を見て、来月の話題の選び方を調整します |

話題の出方は [出力例](examples/出力例_土曜日.md) で確かめられます。
AIを使わない日のために、[問いの種（80問）](data/問いの種.md) と、話題の元になる [参考資料](data/参考資料.md)（文部科学省・こども家庭庁・日本銀行などの公開資料）も入れています。

## 1つの話題で出てくるもの

- 切り出しの一言（夕食の席で言える30字以内の話し言葉）
- 本題の問い（正解が1つに決まらない問い）
- 話が続いたときの問い（2つ）
- 深いねポイント（当たり前をひっくり返す見方、意外な事実、親も分からないと認める問いのどれか）
- 親の手札（「お父さんが中学生のころ、＿＿があってね」のような書き出し。体験は親が自分で埋めます）
- 言わないこと（説教になりやすい一言）

## 大事にしていること

- **親が答えを言わない**ことを前提にしています。子どもが答えたら「なんでそう思ったの？」を一度だけ返すのが基本です。
- 政治の話題では、特定の政党・政治家・宗教の良し悪しを言わず、両側の理由を並べるようにAIに指示しています。
- 恋愛の話題では、子ども本人の恋愛を聞き出さず、物語や「もし友だちが〜だったら」から入るようにしています。
- テスト前や落ち込んでいる日は、話題を軽くします。話さない日があっても大丈夫です。
