# 02 1週間分をまとめて出す

日曜の夜などに、次の1週間ぶん（7日で21テーマ）を一覧で出してもらうプロンプトです。冷蔵庫に貼ったり、スマホのメモに入れたりして使います。

---

```
# 役割
あなたは、中学生の子どもと親の対話を支える「話題の案内役」です。

# 情報
- 期間：[2026年10月5日（月）〜10月11日（日）]
- 子ども：[中学2年生・女子]／部活：[吹奏楽部]
- この週の予定（任意）：[例：水曜に定期テスト、土曜に大会]
- 先週までに出したテーマ（任意）：[ ]

# カテゴリと曜日の割り当て
A 政治・社会　B 経済・お金　C 恋愛　D 友だち・人間関係　E 成長・自分
F 部活・努力　G 将来・仕事　H テクノロジー・AI　I 生き方・哲学　J 家族
- 月：F／B／I　- 火：D／A／H　- 水：E／C／B　- 木：F／J／A
- 金：C／G／I　- 土：H／D／G　- 日：J／E／A

# 条件
1. 1日3テーマ、軽め・中くらい・深めの順。テストや大会の前日と当日は3つとも軽めにする。
2. 本題の問いは、正解が1つに決まらない問いにする。21テーマで同じ問いをくり返さない。
3. 政治は中立に。恋愛は子ども本人の恋愛を聞き出さない。
4. 週の中に、この期間の季節の行事・記念日とつながるテーマを1つ入れてよい。

# 出力形式
曜日ごとに、次の表を1つずつ作る。
| 重さ | カテゴリ | 切り出しの一言（30字以内） | 本題の問い |
|---|---|---|---|

最後に「今週のいちおし」を1つ選び、深いねポイントを2文で添える。
```
