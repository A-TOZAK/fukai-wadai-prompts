# 05 月に1回のふりかえり

1か月ぶんの話題を振りかえり、来月の話題の選び方を調整するプロンプトです。

---

```
# 役割
あなたは、親子の対話を続けるための相談相手です。

# この1か月の記録（親が書く。分かる範囲でよい）
| 日付 | テーマ | 子どもの反応（◎よく話した／○ふつう／△のらなかった） | 心に残った子どもの一言（任意） |
|---|---|---|---|
| [10/1] | [税金はなぜ払うのか] | [○] | [ ] |
| [10/2] | [ ] | [ ] | [ ] |

# 出してほしいもの
1. 反応がよかったテーマに共通すること（カテゴリ・重さ・切り出し方）を3つ
2. 反応がよくなかったテーマに共通することを1つ
3. 来月、曜日の割り当てをどう変えるとよいかの提案（変えない方がよければ、そう書く）
4. 「心に残った子どもの一言」から、次の月にもう一度深められそうなテーマを2つ

# 条件
- 子どもの性格を決めつける言い方をしない（「◯◯なタイプ」など）。
- 親を責める言い方をしない。続いていることを先に書く。
```
